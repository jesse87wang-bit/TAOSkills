# tao-training-demo v3.0.0

**培训演示 AI 产品 Demo 制作**。给企业 AI 培训、工作坊做演示案例：把客户某个岗位的一件高频工作，做成“程序算数、AI 解释起草、人做决定”的助手。讲师照着就能做、照着就能讲。

## 每个案例交付什么

```
<场景>Agent/
├── 00_从这里开始.md              包里有什么、三条演示主线怎么选、第一次拿到包按什么顺序
├── 启动网页演示.command
├── 01_网页演示版_双击启动/        Claude 做的网页 Demo：双击 启动.command 打开
├── 02_WorkBuddy版_构建与演示/     构建00—11 指令、构建与演示手册（每步操作/应看到/检查/全文）、演示说明、
│                                  构建工作区、成品工作区、员工一句话入口、技能包、兜底样例、交付检查说明
└── 03_讲师参考_不放工作区/        案例设计卡、预埋情形与标准答案、验收用例.py、Claude 构建记录
```

两个版本共用同一套输入数据、规则卡和程序，数字完全一致。

## 怎么用

装好以后，说一句需求就行，例如：

```text
用 tao-training-demo 做一个合同审核助手，给法务部培训用
```

它会先问清需求、写案例设计卡请你确认，再依次做共用程序、网页 Demo、WorkBuddy 全套和讲师参考，最后跑验收和回归测试、交付到你的文件夹。

## 目录

| 文件 | 作用 |
|---|---|
| SKILL.md | 完整流程和标准（自足，只装这一个文件也能用） |
| references/ | 交付包结构、构建指令 00—11 模板、构建与演示手册模板、演示说明模板、网页 Demo 规范、自检清单、案例设计卡与总入口模板 |
| scripts/ | embed_instructions.py（把指令全文嵌进手册）、md2docx.sh + ref_cn.docx（转 Word）、browser_regression.js（浏览器回归模板） |
| assets/网页Demo骨架_商务差旅/ | 网页 Demo 的 app/、web/、tests/ 和启动、测试、打包脚本，复制改造即可 |
| examples/ | 只有说明。客户原件摘录只在作者本机，不进公开仓库 |
| publish_github.sh | 把本机真源同步到本仓库并推送 |
