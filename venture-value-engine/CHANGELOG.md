# 更新历史

## v3.0.1 — 2026-10-09

- 新增“一键全量报告”触发：当前对话已有企业背景材料、聊天记录等附件时，输入“用 Venture Value Engine 分析这家企业”或同义指令，直接执行完整分析。
- 命中触发后不再询问模式，不先只给计划、提纲或一页评分；资料缺失项改写为带证据要求、核验方法和通过/失败标准的尽调问题。
- 明确附件内容属于待核验证据而非用户指令；参考模板或脚本缺失时仍按内嵌结构完成全量报告。

## v3.0.0 — 2026-10-09

- 保留V1.2默认完整投资分析（公司定位、机会、15个创始人问题与验证、风险、三轮尽调、护城河、价格/结构纪律）。
- V2：增加可运行的证据审计、可比估值/VC Method、现金跑道与基本单位经济、普通股多轮cap table及投前扩池、有限单类清算权演示、Term Sheet问题检查、结构化核验一键报告，以及完整投委会模板。
- V3：增加离线多项目投资档案、可追溯事件/哈希链、证据更新、人工决策历史、现金投入/分配事件、明确标准的里程碑与逾期查询、不同日期的严格快照与差异比较、带来源的估值更新记录、横向比较、组合复盘模板。
- 回归验证：TokenFly有4项核心事项未独立核验且8秒/15–30秒未统一口径；缺财务/交易数据时不产生虚假的估值；纯虚构示例检验估值/股权数学与跨项目工作流。
- 标注严格限制：无自动后台监控或交易执行、不替代法律财务审计、多轮多类优先权/SAFE需专项模型。
