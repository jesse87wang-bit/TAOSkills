# 音效（自备，不随仓库分发）

音效来自剪映音效库，使用者需要有剪映的使用授权，所以仓库里不放音频文件。
在剪映「音效」里找到下面 6 个，导出成 wav（48kHz 立体声，只保留单次音效、开头不留空白），按文件名放进本目录：

| 文件名 | 剪映里的名字 | 用途 |
|---|---|---|
| `deng.wav` | 科技 点击 系统音 | 「噔-楞」：每张玻璃卡弹出 |
| `ding3.wav` | 科幻点击叮的音效 | 三连叮：重音、划掉、盖章 |
| `app.wav` | App 界面点击 | 短点击：小图标、列表逐行亮起 |
| `tone.wav` | 科技点击系统音 | 柔和系统音：胸前大字/结论条 |
| `xp.wav` | XP系统音提示音、游戏界面点 | 提示音：章节标 |
| `ui.wav` | UI界面按钮点击 | 按钮点击：副标题、提示条 |

`make_video.py doctor` 会把这 6 个文件和基准的 sha256（`../assets.json`）比对：
一致 = 声音和第一条成片完全相同；不一致也能出片，只是音色会不同。
