# Classroom Methods Provenance｜v3.1-rc1

> 用途：记录课堂材料如何被蒸馏为 Skill 规则。此文件是来源与工程化边界说明，不代表教师、学校或机构对本 Skill 的授权、背书或认可。

## 来源分级

- SOURCE-A：课堂/著作明确表达的概念、模型、原则。
- SOURCE-B：从多个课堂案例中归纳出的稳定思考模式。
- ENGINE-C：为了让 Agent 可执行、可测试、跨 Agent 更稳定而加入的工程协议。

## 1. DESIGN_OVER_OPTIMIZATION

- 来源：SOURCE-A + ENGINE-C
- 课堂增量：最高级财务思维强调“设计”，区别于在既有框架中的局部优化；课堂现金与重资产案例进一步体现通过金融工具、交易结构、商业模式设计改变财务结果。
- 工程化：LEVEL 2/3 强制执行一次 REDESIGN_PASS，并加入 WHO-BEARS-WHAT。
- 禁止误读：不是“所有企业都应追求复杂金融结构”，而是要求在重大问题中检查能否改变产生问题的规则本身。

## 2. QUALITATIVE_BEFORE_QUANTITATIVE

- 来源：SOURCE-B + ENGINE-C
- 课堂增量：企业价值分析反复从战略、行业、产业位置、商业模式和企业阶段解释财务结果，而非把单一财务比例当作结论。
- 工程化：TRACK → POSITION → MODEL → LIFECYCLE → OBJECTIVE 五项前置。

## 3. QUALITY_BEFORE_QUANTITY

- 来源：SOURCE-B + ENGINE-C
- 课堂增量：收入、利润、研发、资产等数字均需要继续拆结构、来源、质量和可持续性；总量不能自动代表价值。
- 工程化：AMOUNT → COMPOSITION → QUALITY → SUSTAINABILITY → VALUE CONSEQUENCE。

## 4. LIFECYCLE_METRIC_SWITCH

- 来源：SOURCE-A/B + ENGINE-C
- 课堂增量：生存、发展、投入期、成熟期的关注重点不同；早期科技企业不能机械用成熟企业净利润尺子。
- 工程化：探索/验证/扩张/成熟/转型/退出六阶段 Metric Router。

## 5. CAPABILITY_TRANSFER_GATE

- 来源：SOURCE-A/B + ENGINE-C
- 课堂增量：第二曲线和多元化强调深耕核心、有序延伸、战略克制；表面场景相关不代表底层能力协同。
- 工程化：客户、技术、品牌、渠道、供应链、组织六项迁移测试；仅在第二曲线/跨界等场景触发。

## 6. MILESTONE / REAL OPTION

- 来源：SOURCE-A + ENGINE-C
- 课堂增量：创新药等里程碑明确项目，可把每阶段成功/失败概率、投入和收益放入决策树/期权思路。
- 工程化：高不确定项目采用“里程碑 → 概率更新 → 再下注”；新增资本必须说明是在买增长、买能力还是买证据。

## 7. ENDGAME_BACKCASTING

- 来源：SOURCE-A
- 课堂增量：缺乏历史的新产业不适合机械从历史外推，可先判断成熟终局，再倒推成长路径。
- 工程化：终局市场 → 稳态竞争 → 合理份额 → 稳态经济模型 → 里程碑 → Base/Bull/Bear → 反证。

## 8. OFF_BALANCE_VALUE_AND_RISK

- 来源：SOURCE-A/B + ENGINE-C
- 课堂增量：企业价值可能来自未充分入表的品牌、数据、生态等；风险也可能藏在担保、或有负债、收益兜底、关联关系和生态结构中。
- 工程化：重大融资、投资、并购、生态问题触发表外价值/风险双向扫描。

## 9. VALUE_CREATION_TRINITY

- 来源：SOURCE-A
- 课堂增量：持续价值创造同时关注盈利、持续增长以及为获得收益所投入资本/资金成本。
- 工程化：任何增长判断都追问“赚不赚钱、能不能持续、占用多少资本”。

## 10. ENGINE-C 明确清单

以下是工程规则，不应归因于教师原话：
- Complexity Gate 的 L1/L2/L3 分级
- JN 六问
- WHO-BEARS-WHAT 五问
- Money + Rights + Resources + Constraints
- 失败模式标签体系
- 120 分 Benchmark 评分体系
- 跨 Agent Schema / Renderer 强协议
- 发布门槛与回归测试协议

## 原则

课堂案例可进入 references，但只有能够改变判断顺序、边界、方案设计或资本下注方式的内容，才进入 Decision Engine。避免把 Skill 退化成课程摘要或知识库。
