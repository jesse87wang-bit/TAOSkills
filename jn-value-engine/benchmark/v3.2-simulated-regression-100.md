## 失败集中区

### 1. SCOPE_OVERREACH｜5题

- **013 诉讼**：价值引擎可判断回款、资本占用和关系价值，但不应替代诉讼策略/法律意见。
- **017 锁汇**：可判断风险敞口与对冲经济性，但具体远期/期权执行属于 Treasury 专业模块。
- **030 减值**：可挑战经营假设与未来现金流，但“是否减值/怎么计提”属于会计准则与审计结论。
- **084 50/50治理僵局**：可识别控制权风险，但章程、协议、表决和退出机制要交治理/法律专业设计。
- **087 员工持股**：可判断人才价值和激励目标，但具体持股架构、税务、合规不能由本 Skill 单独下结论。

### 2. 为什么这是 Interaction 问题，而不只是 Scope 文案问题

v3.2 已在“让位区”写明专业边界，但 Interaction Router 只有 QUICK / HIGH-STAKES QUICK / FULL 三种展示路径。遇到上述题时，模型仍会先选择一种“企业价值回答模式”，容易让用户误以为这是完整专业结论。

因此需要独立路由：

`SPECIALIST_BOUNDARY_ROUTE`

输出结构建议：
1. 企业价值层判断；
2. 本 Skill 能回答到哪里；
3. 哪个专业结论必须由谁验证；
4. 在专业结果出来前，企业应保留什么选择权；
5. 什么结果会改变企业价值判断。

## v3.3 候选结论

**只修 Interaction Router，不改 v3.1 Decision Engine。**

新增：`SPECIALIST_BOUNDARY_ROUTE [ENGINE-C]`

触发条件：问题核心决策依赖法律、税务、会计/审计、Treasury/衍生品、监管许可等专业结论，且该专业结论会实质改变 GO / NO_GO / HOLD。

禁止：
- 把“建议咨询专业人士”当一句免责废话；
- 直接让位后不提供企业价值层分析；
- 对专业执行细节给伪确定答案。

建议版本状态：**v3.2 保持当前稳定版；建立 v3.3-scope-router-rc1，不立即修改 main。**
