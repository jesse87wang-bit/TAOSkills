# jn-value-engine Benchmark

本目录用于验证 Skill 是否真的提高企业价值判断，而不是只让回答更长、更像咨询报告。

## 文件

- `regression-20.md`：v3.1 高敏感回归集 + 反向压力集。
- `failure-modes.md`：失败模式库与记录模板。

## 推荐测试顺序

1. 同模型控制测试：v3.0 vs v3.1-rc1。
2. 记录120分评分、回答长度、失败模式。
3. 对退化题做规则删减，不以增加 Prompt 长度作为默认修复。
4. 通过后再做跨 Agent 隐藏版本盲测。
5. 只有达到 `SKILL.v3.1-rc1.md` 中发布门槛，才考虑替换 main 正式版。

## 公平性

- 不允许任何参测方搜索题目对应现实企业的最终结局。
- 所有参测方获得同样的题面信息。
- 缺失事实允许指出“需验证”，不得因 Benchmark 需要而编造。
- 评分对象是决策程序，不是文风、篇幅或事后结果拟合。

## 版本纪律

任何新规则必须回答：
- 它修复了哪个失败模式？
- 哪些题能检测它？
- 是否导致其他题退化？
- 它属于 SOURCE-A、SOURCE-B 还是 ENGINE-C？

没有可验证增益的规则，不进入正式 Skill。
