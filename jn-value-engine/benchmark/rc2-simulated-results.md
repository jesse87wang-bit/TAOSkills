# jn-value-engine v3.1-RC2｜单窗口受控模拟 Benchmark

> 状态：Development evidence only / 非独立跨 Agent 实验
>
> 本结果是在同一模型窗口内按冻结协议分别模拟普通 GPT、资深 CFO Prompt、v3.0、v3.1-RC2，并用同一 120 分 rubric 复核。它用于版本选择与工程回归，不应对外表述为独立多模型实测。

## 1. 测试集

- 20 道高敏感企业价值决策题
- 5 道 Overthinking 反向压力题
- 禁止搜索现实结局
- RC2 测试过程中不修改规则

## 2. 20 题主测试｜模拟汇总

| 系统 | 平均分 /120 | 相对 v3.0 |
|---|---:|---:|
| 普通 GPT | 79.8 | -15.3% |
| 资深 CFO Prompt | 88.9 | -5.6% |
| jn-value-engine v3.0 | 94.2 | 基准 |
| jn-value-engine v3.1-RC1 | 100.9 | +7.1% |
| **jn-value-engine v3.1-RC2** | **102.3** | **+8.6%** |

说明：分数是受控模拟评估值，不代表统计显著性，也不代表独立模型之间的客观能力排名。

## 3. 两项新增能力

| 能力 | v3.0 | RC2 | 相对提升 |
|---|---:|---:|---:|
| 数字质量 / 结构穿透 | 7.3 | 8.9 | +21.9% |
| 重新设计能力 | 6.8 | 8.5 | +25.0% |

RC2 保留了 RC1 的主要新增价值，同时通过 Materiality Gate 减少为了第三方案而第三方案。

## 4. 5 道反向压力题

| 测试题 | v3.0 | RC1 原始倾向 | RC2 |
|---|---:|---:|---:|
| 设备维修 20 万 vs 换新 35 万 | 103 | 95 | 106 |
| 两个同类供应商差价 3% 是否切换 | 101 | 96 | 103 |
| 提前付款获 2% 折扣 | 105 | 98 | 107 |
| 成熟门店是否增加 1 名员工 | 99 | 94 | 101 |
| 已验证软件续费 30 万还是停用 | 102 | 98 | 104 |

结论：Complexity Gate 2.0 明显降低 OVERTHINKING_TRAP；LEVEL 1 默认走 FAST ECONOMICS，不显式展开赛道、终局、生态、第二曲线等无关模块。

## 5. RC2 三项修复效果

### COMPLEXITY_GATE 2.0
通过。简单题能主动跳过复杂模块，而不是只给问题贴 LEVEL 标签。

### REDESIGN_MATERIALITY_GATE
通过。重大问题仍检查重新设计机会，但允许结论为“没有必要重设计”，不再强迫 A/B/C 都具有创新结构。

### MINIMUM_EVIDENCE_GATE
基本通过。信息不足题更稳定输出 CONDITIONAL DECISION，并优先指出 1—3 个真正会改变结论的事实，而不是编造 KPI 或给伪精确判断。

## 6. Failure Mode 回归

- METRIC_TRAP：低
- A_B_TRAP：低
- GROWTH_TRAP：低
- FINANCING_TRAP：低
- STORY_TRAP：中低；新产业终局推演仍需防止把终局假设当事实
- OVERTHINKING_TRAP：较 RC1 明显下降
- REDESIGN_FOR_REDESIGN_TRAP：较 RC1 明显下降
- PREMATURE_DECISION_TRAP：下降，但在用户只给一句话的复杂问题中仍需保留条件性表达

## 7. Release Gate 检查

| Gate | 要求 | RC2 模拟结果 | 状态 |
|---|---|---|---|
| 总体相对 v3.0 | >= +8% | +8.6% | PASS |
| 数字质量/结构穿透 | >= +20% | +21.9% | PASS |
| 重新设计能力 | >= +20% | +25.0% | PASS |
| 原有能力退化 | 任一维度不得 >5% | 未发现 >5% | PASS（模拟） |
| Overthinking | 不高于 v3.0 | 压力题未高于 | PASS（模拟） |
| 回答长度 | 增幅 <=20% | 受 Complexity Gate 控制，模拟未超过 | PASS（模拟） |

## 8. 工程结论

**RC2 在单窗口受控模拟 Benchmark 中达到预设 Release Gate。**

但这只意味着：RC2 已具备成为正式 v3.1 的工程候选资格；不意味着已经获得独立跨模型验证。

建议发布口径：

> v3.1 经过 100 题问题库建设、20 题高敏感回归、5 题反向压力和单窗口受控模拟测试后，进入正式候选。其主要新增能力是：看数字结构与质量、从财务穿透经营机制、在有实质价值时重新设计、并根据问题复杂度自动控制分析深度。

禁止公开口径：

> “独立实测提升 8.6%” / “全面超过资深 CFO” / “多个 Agent 验证领先”。

这些结论当前证据不支持。
