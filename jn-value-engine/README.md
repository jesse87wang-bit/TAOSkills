# jn-value-engine

> 企业家重大资本决策引擎

`jn-value-engine` 是一个面向企业家重大经营与资本决策的 AI Skill。它基于《贾宁财务讲义》与《初创企业价值创造与资本战略》课程框架蒸馏，并经过多轮红队测试和真实企业问题 Benchmark 迭代。

## 它不是

- 贾宁老师本人或“数字分身”
- 财务知识问答机器人
- 万能 CFO
- 会计、税务、审计、法律等专业服务的替代品

## 它适合解决什么

- 要不要扩产、开店、进入新市场？
- 要不要融资？该拿债权还是股权？
- 第二曲线、新业务、研发项目要不要继续投？
- 自建还是外包？直营还是加盟？
- 重大数字化 / AI 投资是否值得？
- 并购、出售、退出是否创造价值？
- 公司还能赚钱，但创始人已经很累，要不要卖？
- 多个项目争夺有限资本时，钱怎么配置？

核心不是“算得更复杂”，而是：

**先检查是不是问错了问题 → 找关键矛盾 → 从数字穿透经营机制 → 设计第三方案 → 控制下注 → 明确停止与反转条件。**

## 核心决策架构

`DEFINE → MECHANISM → DESIGN → DECIDE`

其中包括：

- `OBJECTIVE_FUNCTION`：先定义真正想最大化什么
- `KEY_CONTRADICTION`：找 1—2 个真正决定结果的矛盾
- `LIFECYCLE_CHECK`：探索期、验证期、扩张期、成熟期使用不同资本纪律
- `CAUSE_BEFORE_JUDGMENT`：先解释指标为什么形成，再判断好坏
- `CAPITAL_EFFICIENCY`：增长必须接受资本效率检验
- `MOAT_VS_EFFICIENCY`：不机械崇拜轻资产
- `COUNTERFACTUAL_BASELINE`：A / B / Do Nothing 都要比较
- `OPTIONALITY`：高不确定性问题优先保留选择权
- `EVIDENCE_LADDER`：证据多强，就下多大的注
- `CAPITAL_MATCHING`：资金期限、刚性、控制权与风险相匹配
- `CASH_SURVIVAL`：价值正确不代表能活到价值兑现
- `FALSIFICATION`：明确什么证据会让当前结论反转

## 使用

将本目录中的 `SKILL.md` 安装/加载到支持 Skills 的 AI 环境，然后直接输入真实企业问题。

建议不要出“考试题”，而是直接问正在纠结的真实决策。例如：

> 公司一年营收约 1 亿元，经营还能正常运转，但已经没有增长空间，我本人也非常疲惫。现在考虑卖掉公司，再做新赛道或者转做投资，我应该怎么判断？

## 当前版本

**v2.1**

相对上一版新增：

1. `SCOPE_ROUTER`：区分重大资本决策、协同区与专业技术让位区。
2. `EXECUTIVE_COMPRESSION`：默认先输出“一句话判断 + 关键矛盾 + 下一步”。
3. `DIVISIBILITY_CHECK`：防止所有重大投资都被机械建议成“小步试点”。

## Benchmark

本 Skill 已使用真实企业问题进行对照测试：普通 GPT vs 资深 CFO Prompt vs `jn-value-engine`。

当前观察到的主要增益集中在：

- 问题重构
- 重大资本配置
- 增长质量
- 融资目的与资本匹配
- 第三方案 / 选择权
- 商业假设审计

专业会计准则、税务、审计、具体衍生品交易执行等问题，不是本 Skill 的主战场。

## 方法来源边界

本项目严格区分：

- **SOURCE-A**：课程/著作明确出现的概念、模型、原则
- **SOURCE-B**：从多个课程案例中归纳出的稳定思考模式
- **ENGINE-C**：红队测试后加入的 AI 决策工程规则

ENGINE-C 不应被表述为贾宁老师本人提出或独创的方法。
