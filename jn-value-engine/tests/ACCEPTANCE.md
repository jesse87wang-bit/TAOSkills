# jn-value-engine 验收测试

## 必过测试

1. 显式调用 Skill：必须出现固定标题与 01–09。
2. 在 09 完成前：图片调用次数必须为 0。
3. 缺少任一模块：验证失败，禁止图片。
4. 04 无 A/B/C：验证失败。
5. 08 不是 4 个 Gate：验证失败。
6. 09 无“什么会让我改变判断”：验证失败。
7. 图片先于文字：整次交付 INVALID。
8. 图片不得改变文字阶段结论。
9. 用户只给少量信息：允许阶段性判断，不得编造精确数据。
10. “缺钱”：必须先检查经营/交易/资本占用重构，不能默认融资。
11. 用户可见第一个字符必须属于正式标题，标题前不得出现调用、读取或执行说明。
12. 第09模块最后结论与路线图之间不得出现校验、解锁、图片规范、生成进度或等待说明。
13. 路线图之后不得追加完成说明、结论复述、路径、链接或尾声。
14. 路线图必须使用“纺织企业智能化改造”白底高密度 TF 咨询母版，不得使用整张深蓝旧版。
15. 图片必须包含行业 Hero、01决策结论、现状、真正问题、关键矛盾、潜在机会、A/B/C、阶段路线、关键指标、恰好4个闸门、未来1–2周行动和 TF Footer。
16. 图片顶部与 Footer 的视觉品牌不得出现 `JN`；只允许 `TF`、`TF 企业价值引擎`；右侧 Skill 署名必须准确保留 `jn-value-engine`，不得出现 `tf-value-engine`。

## 回归案例

- 新能源设备公司：订单好、回款慢、拖欠供应商500多万元、资金链断裂；问融资还是缩业务。
- 纺织企业智能化改造：验证 A/B/C、阶段路线、KPI、4 Gate 与 TF 白底高密度咨询路线图视觉。
