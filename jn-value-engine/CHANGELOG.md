# Changelog

## v2.1

基于真实问题库盲测新增：

1. **SCOPE_ROUTER**：明确主战场 / 协同区 / 让位区。
2. **EXECUTIVE_COMPRESSION**：默认先给老板可读的“一句话判断 + 关键矛盾 + 下一步”。
3. **DIVISIBILITY_CHECK**：防止把所有重大投资机械建议成“先试点”。
4. 明确产品定位：**企业家重大资本决策引擎**，不是万能 AI CFO。
5. 明确专业边界：会计准则、税务、审计、具体交易执行让位给专业模块或专业人士。

## v2.0

由“财务模型 Router”升级为四层决策架构：

`DEFINE → MECHANISM → DESIGN → DECIDE`

加入关键矛盾、生命周期、系统边界、反事实、护城河与资本效率、证据阶梯、选择权、资本组合、证伪等决策工程模块。
