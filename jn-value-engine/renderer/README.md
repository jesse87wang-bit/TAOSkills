# JN Renderer v3.0

目标：让不同 Agent 对同一份 `JN Decision Schema` 产生尽量一致的文字和视觉输出。

## 渲染优先级

1. **SVG / HTML 确定性渲染**（优先）
2. 生成式图片工具（仅当宿主无法程序化渲染时使用）

## 固定画布

- 1200 × 1800
- 竖版 2:3

## 固定纵向区域

- Hero：0—240
- 01 决策结论：260—390
- 02/03/04 三列区：410—750
- 05 方案对比：770—1080
- 06 三阶段路线：1100—1390
- 07 KPI：1410—1510
- 08 决策闸门：1530—1640
- 09 下一步：1660—1730
- Footer：1745—1800

## 内容规则

Renderer 不得重新分析问题。它只能读取 Schema 并填槽位。

禁止：
- 新增 Schema 中没有的结论
- 修改方案排序
- 编造数字/KPI/时间/预算
- 把 `待量化/需验证` 改成精确值
- 改变模块顺序

## 品牌

统一使用：

- `JN 企业价值引擎`
- `jn-value-engine`
- `从问题到价值，从判断到行动`
