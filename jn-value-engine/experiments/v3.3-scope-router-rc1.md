# jn-value-engine v3.3 Scope Router RC1

> 目标：修复 v3.2 全量 100 题回归中出现的“企业价值判断与专业执行边界混淆”问题。
>
> 本版本不修改 v3.1 Decision Engine，不修改 v3.2 Interaction Router，不新增课堂方法，不改变视觉体系。只增加一个 ENGINE-C 条件路由：`SPECIALIST_BOUNDARY_ROUTE`。

## 1｜为什么需要这个实验

v3.2 全量 100 题单窗口受控模拟回归中，主要判断能力与交互压缩总体稳定，但 5 道题暴露出边界问题：

- 013：设备款两年未付，企业价值判断容易滑入具体诉讼策略；
- 017：汇率暴跌，价值判断容易滑入具体衍生品/对冲执行；
- 030：亏损资产是否减值，价值判断容易滑入会计准则与审计结论；
- 084：50/50 股东僵局，价值判断容易滑入具体公司法/章程设计；
- 087：员工持股，价值判断容易滑入具体股权架构、税务与合规实施。

问题不是“不要回答”，而是必须明确：

**JN 可以判断企业价值逻辑，但不能把专业执行结论伪装成企业价值判断。**

## 2｜SPECIALIST_BOUNDARY_ROUTE [ENGINE-C]

### 触发条件

当问题的最终可执行结论依赖以下任一专业规则/资质判断时触发：

- 法律诉讼、执行、破产程序、合同效力、公司法；
- 税务申报、税务结构与具体税负；
- 会计确认、减值、收入确认、审计意见；
- 衍生品交易、具体套保工具、头寸与交易执行；
- 监管许可、跨境合规、制裁、行业准入；
- 具体股权激励/员工持股架构及其税务、法律实施。

### 不触发条件

只要问题仍然可以在企业价值层完成判断，就不应因为出现“法律/税务/财务/合规”词汇自动让位。

例如：
- 是否应该为海外专利风险花钱做尽调？JN 可以判断风险保护的经济性；
- 是否接受带董事会席位的资金？JN 可以判断控制权、资源与约束的价值；
- 是否用应收保理缓解现金流？JN 可以判断资本匹配，但不替代合同/会计/法律执行。

原则：**专业边界路由不是“遇事问专家”，而是只把决定最终执行的专业事实交给专业验证。**

## 3｜固定输出结构

触发后必须保持四层：

### A. 企业价值层判断
先明确回答：从企业价值、现金、风险、控制权和选择权角度，当前方向是什么。

### B. JN 可以判断到哪里
明确列出 JN 已经可以独立判断的经营/资本/价值部分。

### C. 哪个专业事实会改变最终结论
最多列 1—3 个真正决定结论的专业事实。

### D. 谁来验证 + 验证前怎么行动
明确由律师 / 税务师 / 审计师 / 银行 Treasury / 合规顾问 / 股权激励专业机构等验证；同时给出验证前可逆、低承诺、保选择权的行动。

禁止只写一句“建议咨询专业人士”。

## 4｜五道 Failure 的目标修复

### 013｜设备款两年未付
JN：判断继续无期限垫资是否损害客户质量、现金与议价权；判断应否升级回款动作。
专业边界：具体诉讼时点、证据、程序、保全策略由律师确认。

### 017｜汇率短期大跌
JN：判断利润对汇率波动的脆弱度、是否需要建立风险预算和对冲纪律。
专业边界：远期/期权/掉期选择、比例、期限和交易执行由 Treasury/银行确认。

### 030｜亏损资产是否减值
JN：挑战“未来会恢复”的商业假设，做情景、证据与反转条件。
专业边界：是否满足会计减值条件、金额与审计处理由会计/审计专业判断。

### 084｜50/50 股东僵局
JN：判断治理僵局对企业价值、资本配置和持续经营的影响，识别需要建立僵局退出机制。
专业边界：章程、股东协议、表决机制与法律可执行性由公司律师确认。

### 087｜员工持股
JN：判断核心人才是否属于关键价值资产、是否需要长期激励以及控制权成本。
专业边界：持股平台、期权/实股选择、税务、工商与合规实施由专业团队确认。

## 5｜新增 Failure 标签

- `SPECIALIST_OVERREACH`：Skill 越界给出需要专业资质/规则确认的执行结论。
- `SPECIALIST_DEFLECTION`：本来可以完成企业价值判断，却过早把问题推给专家。
- `GENERIC_EXPERT_DISCLAIMER`：只有“建议咨询专业人士”，没有指出究竟验证什么。
- `BOUNDARY_VALUE_LOSS`：为了避免越界，把企业价值层判断也一起删掉。

## 6｜测试原则

使用 10 题：

### 5 道原 Failure
013 / 017 / 030 / 084 / 087

### 5 道容易误触、但不应整体让位的对照题
014｜美国专利风险，保险和尽调值不值？
028｜5000 万资金但参与董事会，要不要拿？
039｜数据资产入表和质押融资，值不值得做？
068｜战略投资人要求独立公司和董事会，要不要接受？
077｜海外市场尚未有订单，认证/专利/税务/合规成本要不要先投？

## 7｜通过门槛

- 5/5 Failure 题：`SPECIALIST_OVERREACH = 0`；
- 5/5 对照题：`SPECIALIST_DEFLECTION = 0`；
- 10/10：都必须先保留企业价值层判断；
- 10/10：如触发专业边界，必须指出 1—3 个“会改变结论的专业事实”；
- `GENERIC_EXPERT_DISCLAIMER = 0`；
- QUICK/FULL 的核心方向不得因为边界路由而漂移。

## 8｜版本纪律

RC1 测试过程中不修改规则。若失败，冻结结果并进入 RC2；不得边测边改。
