# TAO 白板图风格约定

## 一句话

**一张图一个主张。** 讲不完就拆两张，不要往一张里塞。

## 画布

- 逻辑尺寸 1600×900，标题 `s.title(800, 40, ...)`
- 标题居中于**内容**，不是居中于画布——内容偏左时标题也要跟着左移
- 四周留白舒服即可，超过半屏的空白说明版式没排满，要收紧

## 字号

| 用途 | 字号 |
| --- | --- |
| 主标题 | 36 |
| 副标题 / 小节标签 | 18–22 |
| 图内主标签 | 19–24 |
| 卡片正文 | 17 |
| 便签旁白 | 18–20 |
| 箭头注解 / 脚注 | 14–17 |

## 配色

只用 `PALETTE`，每张图**一个重点色**，其余压成 `gray`：

| 色 | 语义 |
| --- | --- |
| `green` | 好的做法 / 现在 / 结果对 |
| `red` | 坏的做法 / 以前 / 出问题 |
| `violet` | 这张图要讲的核心新概念 |
| `yellow` | 旁白、手册、人 |
| `blue` | 人和输入 |
| `gray` | 背景角色、被对比的中立项 |

同一套稿子里，同一个概念在不同分镜必须用同一个色（比如 Agent 全篇都是绿）。

## 惯用手法

- **虚线框 = 一个整体**：把「搜索→整理→出报告」框起来，标上 Agent
- **同一个中间件重复出现**：对比两条管线时，中间那个盒子写「同一个 LLM」，
  强调变的是输入不是模型
- **量表用填充比例**：多/少/刚好画成同一条槽，填充宽度不同，
  超出部分画成虚线块标「溢出 = 忘掉」
- **收敛靠线数**：以前是 N 根异色线（实线/虚线/粗线混用，表示接口各不相同），
  现在是 1 根线进一个盒子再散开
- **金句进便签**：稿子里那句要被截图转发的话，单独放底部 `sticky`

## 不要做的事

- 不要给每张图都画流程图
- 不要用超过三种颜色讲一件事
- 不要把稿子原文整段贴进图里——图上只留关键词和金句
- 不要手改生成出来的 JSON，改脚本重跑
