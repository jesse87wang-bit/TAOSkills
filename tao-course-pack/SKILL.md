# tao-course-pack：线下AI培训课程包

把「课件 + 讲稿 + 大纲」变成讲师拿去就能上课的一整套资料。方法来自一门高校线下《AI短视频创作与剪辑实战》课两期的实战备课（2026-11，75人/15—18组/1.5—2天），换课程只换实例与场景，体系不变。

目标只有一个：**讲师上台不排障、不翻车、每一页都知道说什么、放什么、学员做什么、出问题怎么办。**

## 技能里的文件

| 文件 | 用途 |
|---|---|
| `scripts/build_material_pack.py` | 第一步：course.json → 《讲师上课材料包》docx（固定格式） |
| `assets/reference.docx` | 材料包的 Word 样式 |
| `scripts/diff_slides.py` | 新旧两版课件逐页比对，列出改动页并出左右对照图 |
| `templates/00_授课台.html`、`templates/投屏窗口.html` | 授课台与投屏窗口；同目录放 `lesson-data.js`（`const LESSON=[...]`）和 `01_课件/p01.jpg…`，把 `{{COURSE_TITLE}}` 换成课名 |
| `examples/course.example.json` | 虚构的最小示例，照它的字段写真课的 course.json |
| `publish_github.sh` | 推送到 GitHub `jesse87wang-bit/TAOSkills` 的 `tao-course-pack/`；只推通用部分，任何一期课的课件、讲稿、学员、素材都不进仓库 |

本地没有 scripts/、assets/、templates/ 时（例如账号里只存了 SKILL.md），先从 https://github.com/jesse87wang-bit/TAOSkills/tree/main/tao-course-pack 取整个目录再用。

## 交付顺序（固定，不要颠倒）

1. **第一步：先出《讲师上课材料包》Word 文件**（结构见第 0.5 节）。这是讲师通读、修改、转发的主文件，所有内容都在这一份里。
2. **第二步：再出现有的工具产出**：授课台与投屏窗口、提示词一键复制、离线卡、打印 PDF、准备总表、实测清单、学员课后资料包等（第 2—12 节）。

两步用同一份逐页数据：一处维护，同时生成 Word 和授课台，不要两边各写一套。最后所有产出放进讲师电脑上这门课的文件夹（如 `<培训项目>/<班次>/<日期>上课`）。

## 0. 先收齐输入

| 输入 | 用途 | 缺了怎么办 |
|---|---|---|
| 课件 PDF/PPT（常是图片型PDF，无文字） | 逐页拆解、截图 p01.jpg… | 必须有，没有不开工 |
| 讲稿 docx | 每页「说什么」、提示词原文 | 没有就先按课件写讲稿骨架，让讲师确认 |
| 课程大纲/日程 | 每页时间点 | 用大纲时长倒推 |
| 学员画像 | 举例口径、难度 | 问主办方：学校层次、专业、是否自带电脑、有无账号/额度 |
| 客户/实操项目 Brief | 商业项目物料 | 没有就做虚构品牌，并标明「虚构」 |
| 讲师自己的作品与原片 | 开场秀、原片成片对比 | 列入待补清单，不用别人的冒充 |
| 上一期的上课文件夹（如 `<培训项目>/<上一班次>/<日期>上课`） | 复用视频、原片、素材、打印件、已验证的视频链接 | 开工前先问在哪；只申请访问这个课程文件夹，不申请整个桌面 |
| 上一版《讲师上课材料包》docx | 结构和详细程度的模板 | 有就照它的结构出新版 |

**先复用再列缺口**：把上一期的 `02_课堂视频`、`04_带练素材`、`05_学员通用素材`、`13_打印材料`、视频链接表逐项对照新课，能用的按新编号复制过来（原文件不动），用 ffprobe 记时长、分辨率、有无音轨。复用完还缺的，才写进「准备不了的」清单。

然后跟讲师确认**红线清单**（下面第 9 节），写进 00_说明 的第一屏。

## 0.5 第一步：《讲师上课材料包》Word（格式固定）

文件名 `00_讲师上课材料包_<版本>.docx`，放上课文件夹根目录，同时发给讲师。**格式照讲师认可的上一版材料包：按小节写，不按页写**。按页一页一块的写法讲师反馈「不清楚」，不要再用。

用 `scripts/build_material_pack.py` 生成，不手排：

```bash
python3 scripts/build_material_pack.py course.json 00_讲师上课材料包_<版本>.docx --md 材料包.md
```

`course.json` 的字段见脚本开头说明和 `examples/course.example.json`（虚构示例）。逐页数据 `pages` 和授课台的 `lesson-data.js` 是同一份；另外只需要写「模块→小节→页码范围」的分组和前后各部分的 Markdown。每门课的 course.json、导出脚本放上课文件夹的制作目录，不进技能。

**固定结构**

开头「使用说明、受众差异与课堂时间轴」：
1. 标题＋一行日期地点人数（不加目录页）。
2. 一段说明：依据哪份讲稿、哪版课件；屏幕和讲稿不一致的以屏幕为准。
3. 「先办的一件事」：有会卡住整门课的风险（如合办方和工具的冲突）就放这里，没有就省略。
4. 新课件核对结果（有新版课件时）：结果｜页｜内容。
5. 和上一版的不同（表）；受众画像与说话方式（表，上一期说法→这一期改成→原因）；材料包结构（部分｜内容｜给谁）。
6. 分钟级课堂时间轴：**一个小节一行**（时间｜环节（小节）｜学员在做什么｜材料），每天单独一行日期，课间单列；后面一行编号约定。

第一部分「讲师逐字讲稿」：
- 按模块分（如「讲师逐字讲稿·模块二 看懂AI、需求卡与口播稿（8日14:30—15:30）」），模块开头一句「这一段要达成什么」。
- 每个模块 3—8 个小节，小节标题「2.3 好提示词的六要素（14:52—15:00，P17—P18）」，一节覆盖 1—4 页 PPT。全课一般 35—45 个小节。
- 每节顺序固定：【PPT】一行列出本节各页标题 →（多页时）【翻到 Pxx】→ 口播用引用块（灰色左竖线、斜体，可以直接念）→ 动作行【不说话，直接播 Y5】【投票】等单独成行 →【学员】【讲师动作】【计时】→ 本节合并一次的【素材】【翻车预案】【冷场】→ 本节附表（如合规页「卡片｜答案｜讲师解释」）。
- 模块末尾一句【转训提示】。
- 逐页的「课前核对」不散在讲稿里，统一收进第一部分末尾「本部分的课前核对」一张表（页｜标题｜要核对的事）。
- 第一部分末尾附开场逐字稿两版、冷场备用句、自我介绍30秒版、彩排要求。

第二—七部分（内容同前，标题固定）：
- 第二部分 提示词全集：编号表（编号｜名称｜用在｜谁用）、发群时间表、每条全文（代码块）、演示示意输出（标明课前实跑后替换）。
- 第三部分 演示视频与素材准备清单：编号总表**只留四列**：编号｜内容（时长·用在·用途）｜状态｜下一步／文件；状态如实写，开头写一句「当前不是全部就绪」；复用上一期素材表；每页配套视频；带练口播稿；采购。
- 第四部分 学员练习材料：方法速查＋全部表单。
- 第五部分 实操项目包：任务书、品牌卡、客户已确认信息卡、仅讲师口径、反馈、质检表、评分表。
- 第六部分 转训包：30分钟分享课设计、精简课件逐页内容。
- 第七部分 课前准备、助教手册与待核实事项：☐时间表、实测清单、问主办方、学员通知、助教手册、翻车预案总表、打印清单、准备不了的、课后。

**排版（脚本已处理，改脚本时别破坏）**
- 样式用 `assets/reference.docx`：正文 Calibri＋微软雅黑 11pt，标题 16/13/12pt 黑色加粗，引用块＝上一版的 Quote 风格，表格带边框、10pt。上一版材料包本身做 reference-doc 会把表格打散，不要用。
- 表格列宽按内容自动分配、占满版心（pandoc `--columns=20`＋按内容重排分隔行），超过 5 列的表先合并列。
- 填空「____」换成全角「＿＿＿＿」，否则变斜体；段落后紧跟列表自动补空行。
- 生成后转 PDF 抽几页，和上一版并排看：标题层级、引用块、表格列宽、页数（75 人两天的课约 65—75 页）。

## 1. 学员画像校准（最容易被忽略）

- 先判断学员层次。职业院校/非名校学员：少讲清华、大厂、高科技、宏大趋势；多讲「做出来能干什么」：求职作品、社团招新、帮家里店铺、接小单。
- 讲师身份用「每周都在用AI做视频、也经常翻车的创作者」，不念奖项清单，自我介绍≤3分钟。
- 范例优先选学员熟悉的：宿舍、食堂、四六级、招新、毕业季、本校宣传片。
- 讲稿语气轻松幽默、简单易懂；互动用举手、二选一，不点名硬问。
- 不承诺收入，「能赚钱」只讲真实接单路径。
- **课前受众四问**（问主办方，答案写进 00_说明）：来自哪些学校/单位、什么专业/职务、有没有剪过视频、为什么来上这门课。有报名表就要名单里的「单位及职务」列（不要身份证号），自己做画像。还能在学员通知里加 3 题课前问卷。
- 按画像准备**两版开场**（例如名校版/职校版，经营者版/学生版），到现场看人再选。
- 从名单或第一节课里找出积极、有基础的学员，请他们当组长或上台示范，让他们带动别人。不要整堂课只和这三四个人对话。
- 现场冷场≠不想听，但也不能不调整、照原样讲完：立刻切「冷场版」，先放结果（原片→成片、作品）再讲道理，抽象内容往后挪。全场互动只用低门槛方式（举手、二选一、手机投票）。
- 开场 5–10 分钟写逐字稿并背熟，另备 2–3 句冷场时用的话；开场先放作品，不先做自我介绍。

## 2. 逐页拆解 → 授课台

1. 课件逐页转图：`pdftoppm -r 110 -jpeg 原课件.pdf p`，统一命名 p01.jpg…pNN.jpg。图片型PDF要自己看图读内容，不要假设有文字层。
2. 每页一条记录，写进 `lesson-data.js`：

```js
const LESSON=[{
  p: 2, t: "一部手机，能帮家乡小店做什么？", sec: "1.1", type: "开场",
  day: "12月8日 周一 下午", start: "14:01", end: "14:06", min: 5, time: "14:01—14:06",
  say: "口播，一行一句；“”里的可以直接念；【不说话，直接播 Y5】这类【】开头、不含引语的行算动作",
  act: "讲师动作：开课前10分钟试播 Y5；播完举手投票",
  task: "学员此刻要做的事，没有就留空",
  assets: [{n: "Y5 原片→成片（104秒）", f: "02_课堂视频/Y5_原片成片对比.mp4", k: "video"}],  // k: video/img/page/dir/url
  fb: "出问题时的备选：视频打不开就放离线卡／按讲稿继续，台上不排障",
  cold: "冷场版：先放什么结果、跳过哪段",
  fix: "课前要核对的事（进材料包末尾的核对表），没有留空",
  countdown: 0,      // 分钟，>0 时授课台显示「投屏倒计时」按钮
  overlay: null,     // 课件上二维码框空白时叠图：{img, x, y, w, h}（占比）
  brk: 0, brkTime: "" // 本页后课间：分钟数与时间段
}, ...]
```

3. 生成 `00_授课台.html`：左侧讲师视图（本页讲稿要点、动作、计时、下一页预告、素材按钮），一键「打开独立投屏窗口」拖到投影屏；投屏窗口只显示课件图和素材，不显示讲稿。另留「本页投屏」单屏镜像兜底，Esc返回。
4. **每一页都要有 fallback**。没有素材的页写「保留当前课件，按讲稿继续；台上不排障」。开场页和理论页另写一条「冷场版」：先放什么结果、跳过哪段。
5. 时间按页写死到分钟，每半天留 10–15 分钟机动；超时优先砍讲解，不砍学员动手和展示。

## 3. 每页配套范例视频（例子，不是教程）

- 讲什么概念就找**把这个概念用得好的作品**：讲3秒钩子就找钩子用得好的视频，讲拆片就找可拆的成片。**教程只能放「课后」栏**。
- 每条记录：概念（页码）｜视频标题｜链接｜UP主/作者｜时长｜播放量｜发布日期｜课堂用法（放全片/前90秒/只看开头）。
- 逐条打开验证：能播、非「仅自见」、非会员限定、内容和标题一致；需要真人出镜/口播的要确认画面里真有人。打不开的立刻换。
- 每条备一个替补（讲师自制V编号视频或另一条链接）。
- 本校官方素材优先找官方账号原片，找不到写「没找到」，不用网上相似景物冒充。
- 交付两份：完整版表（页码、概念、视频、用法）和精简版（只要 概念｜视频标题｜链接），后者给讲师上课前快速点开。

## 4. 课堂视频与素材编号体系

统一编号，所有文件名带编号，准备总表一张表看全状态：

- **V** 课堂视频（开场秀、范例片、原片成片对比、节奏对比、包装前后对比等）
- **R** 备用录屏（每个现场演示都要有一条真实录屏兜底）
- **M** 素材包（带练素材、学员统一素材、实操项目素材）
- **QY/项目缩写** 实操项目专用素材

准备总表列：编号｜内容｜目标时长｜课堂用途｜当前状态｜仍需输入/下一步。状态如实写：已就绪/待生成/待实拍/待讲师补，**不把文字方案说成成片**，总表开头写一句「当前不是全部就绪」并列出缺口。

配套两张 csv：`来源与下载状态.csv`（作者、来源URL、许可、是否已下载）、`媒体检查记录.csv`（分辨率、时长、帧率、有无音轨、校验）。

## 5. 提示词三件套

- `00_提示词全集_讲师演示版.txt`：按讲稿原文，编号 P1–Pn（创作链路）、A1–An（辅助），含追问轮次（P1追问1/2）。
- 学员版按发群时间分批：`学员版_第一批_21日15点50发群.txt` 这种命名，讲师到点直接复制。
- `单条/` 每条一个 txt；`提示词_一键复制.html` 每条一个复制按钮。
- 演示版提示词要求 AI **短输出**（表格≤6–8行），避免投屏时满屏滚动。
- 学员可用的工具和额度先问清：学员没有额外额度时，学员任务只能用免费工具完成；付费/限量工具（如 LibTV）只讲师演示。

## 6. 演示防翻车

- 每个现场演示：课前在**上课那台电脑**预跑一次 → 录真实录屏（R编号）→ 做离线 HTML 卡（输入、输出截图、要点）。现场卡住超过30秒就切录屏，不在台上排障。
- 备用录屏必须真实录制，不用合成画面冒充；用静图运镜代替模型生成的，文件名标「非模型生成」。
- 工具能力先做「能力检查」：该账号实际能不能出 MP4、能不能自动剪辑/加特效。做不到的不演示，改成「原片 vs 成片」对比 + 讲解工作流。
- AI 做的演示片质量不够时，用讲师真实作品撑场，AI 只演示其中一环。
- **学员那条路线讲师必须亲手跑通**：在学员会用的设备上（如手机，苹果/安卓各一台），只用学员有的免费工具和额度，从头到尾做完一条，把实测的按钮名称写回讲稿。没跑通的路线不能上课。实操第一次重，跑通后反而轻，也最能保证满意度。

## 6.5 AI 自动化部分要加重

实测：学员对「AI 自动剪辑/自动化是怎么做出来的」兴趣远高于剪辑细节和方法论。

- 结构：**结果先行**（30 秒原片→成片对比）→ **拆流程**（识别语音、剪口误、对字幕、做包装、人工复核各一步在做什么）→ **学员亲手跑一个简化版**。
- 前提是学员能自己跑。学员没额度/工具跑不了时，主体只能是演示，学员空手走，满意度反而降。所以先确认学员可用的 AI 功能（软件自带的识别字幕、文字剪辑等），再定主体比例。
- 钩子、结构、镜头这类方法不要单独讲成方法课，改讲成「给 AI 下指令时的检查标准」：不知道什么是好开头，就没法让 AI 剪出好开头。方法页压缩，时间让给 AI 部分。
- 高能环节：第一天晚上收 2–3 位学员的原片（征得同意），讲师用自己的工作流连夜跑完，第二天开场放「原片 vs 成片」。不在台上现场跑，没有翻车风险，又和学员本人相关。
- 讲师工作流案例放在学员动手之前讲，不要放在课程最后。

## 7. 带练素材与学员通用素材

**带练素材**（讲师带着做，学员跟练）：
- 一个贯穿角色（如「小林」）的脚本与时间线、成片片段+SRT。
- 故意带问题的练习素材：口误/停顿/重说的真实口播原片，字幕校对练习（预埋错字）。
- 海报等配套图。目录.html 一页导航。

**学员通用素材**（给没带素材的学员）：
- 正版可商用素材，文件名带来源和ID：`KJ02_校园湖景建筑_Pexels37908129_备选_非本校.mp4`。
- 不是本校的景物必须在文件名标「_备选_非本校」；横版素材附竖屏裁切版。
- 按用途分前缀：KJ空镜、JS近景、BY备用等。

## 8. 实操商业项目包

- **Brief 与品牌卡**给学员；**客户确认口径_仅讲师**单独放（讲师扮演客户时用的标准答案）。
- 范例片先做一条（如25秒），讲解结构，作为评分锚点。
- **实物道具**：拍摄需要学员手持产品就必须买实物，所有组用**同一款**，不混用不同款。按组数采购并多备2–3个。品牌标识用不干胶贴纸，按「每个道具一张」算印量；配一张**贴法参考图**（位置、尺寸、距边距离、3个错误示例）。
- **录制物流**：教室嘈杂不能录音、拥挤不能走动 → 上午布置任务和脚本，午休时段各组出去录（空教室/走廊/户外），每组自己录旁白；多组同时录要错峰分批（A/B/C），不要指望全场静音。定好上传截止时间。
- **课堂内不录人声**：人声在前一晚作业或走廊错峰录；产品类视频优先「字幕＋音乐」，或用软件的文字转语音，不依赖现场旁白。
- **反馈单轮换**：A/B/C 三种反馈单按组号模3分配（1,4,7…拿A；2,5,8…拿B；3,6,9…拿C），初稿后互评，再改 v2。
- 展示与颁奖：每组限时，评分表现场打分。

## 9. 红线与合规（写进说明首屏）

- 网上通用景物不能当本校；本校画面只用主办方/助教实拍或官方授权素材。
- 真实价格不明确就不写价格；广告文案不写无法证实的功效/第一/最。
- 不混用不同款产品拼「同款」。
- AI 生成内容按《人工智能生成合成内容标识办法》（2025-09-01 起施行）加标识。
- 肖像、音乐、他人作品要有授权；不放客户机密。
- 面向学员/客户的材料里**不出现对讲师说的话和思考过程**；仅讲师可见的文件名带「仅讲师」。

## 11. 开课前验收（最后一步，必须真做）

- 授课台从第1页翻到最后一页，每个素材按钮都点开。
- 每个视频在上课电脑上播放一遍（有声、竖屏方向正确）。
- 每条外链在手机和电脑上各打开一次。
- 每个现场演示在上课电脑上预跑一次，对应录屏能播。
- 打印份数 = 人数/组数 × 每份张数，多备10%。
- 学员版提示词发群时间与日程对得上。
- **讲师彩排**：开场 20 分钟录两遍，转写后统计口头禅（嗯/啊/那个）和长停顿，第二遍要比第一遍少。整堂课按授课台带计时走一遍。
- **超额交付自查**：每样材料问一句「主办方或学员看得见吗、课上真会用吗」，用不上的不做。能复用上一期的视频和素材先复用，范例视频优先找现成好作品，不自己从零做。
- 生成一份 `课堂就绪检查表.csv`：编号｜检查项｜结果｜备注，未通过项列在最前。

## 12. 课中调整与课后

- 第一天结束复盘：学员参与度、节奏、哪部分没讲完 → 当晚重排第二天时间表（授课台 time 字段同步改）。
- 课后：给项目介绍人先发感谢，再给主办方/承办老师发感谢 + 一页成果小结（人数、作品数、代表作截图、评价）。
- **成果数据课上就收**：结课前 3 分钟填课后问卷（满意度、最有用的一段、还想学什么），统计作品数，拍代表作截图（作品和照片对外使用要先经主办方同意）。有转训/后续任务的，要和主办方定好跟进人，30 天后再回收一次数据、再出一页小结。这两页小结就是谈下一次合作的依据。
- 问合作方最认可这次课的哪一点，答案就是以后交付的重点。
- 归档：同一体系用于下一期，只换实例与场景（如大学生班 → 有工作经验的青年班），也便于日后做成线上课。
